# Identity CLI

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python: 3.10+](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](pyproject.toml)

**Identity CLI** is a fast, clean, and installable command-line utility for generating realistic synthetic/test identities with persistent local uniqueness guarantees.

It is designed for software testing, mock data generation, QA workflows, demonstrations, and local development.

---

> [!IMPORTANT]
> **Synthetic / Test Data Disclaimer**
>
> All data generated by Identity CLI is strictly synthetic and intended solely for software development, automated testing, and demonstration purposes.
> - **Email Addresses**: Exclusively use reserved example domains (`example.com`, `example.org`, `example.net`) per RFC 2606 and RFC 6761.
> - **Phone Numbers**: Exclusively use reserved fictional/test telephone number ranges (North American Numbering Plan `555-0100` through `555-0199`).
> - No real personal information is scraped, stored, or generated.

---

## Features

- **Persistent Uniqueness Across Runs**: Uses persistent local plain-text records (`names.txt`, `emails.txt`, `phones.txt`) to guarantee that previously generated identities are never repeated in future sessions.
- **Realistic Name Combination**: Full names (`FirstName LastName`) are strictly unique, while allowing natural first-name and last-name reuse across different combinations.
- **Secure Password Generation**: Generates cryptographically secure passwords utilizing Python's `secrets` module containing uppercase letters, lowercase letters, digits, and special characters.
- **Optional Synthetic Phone Numbers**: Reserved test numbers generated on demand (`--phone`).
- **Batch Generation**: Generate up to 10,000 unique identities in a single run (`--count 10`) with mutual uniqueness guarantees within the batch.
- **Excel (.xlsx) Export**: Export generated batches directly into formatted Excel spreadsheets (`--excel`) with frozen headers, automatic column sizing, and collision-safe timestamped file naming.
- **Clean JSON Output**: Pure JSON output mode (`--json`) for automation, scripting, and piping into tools like `jq`.
- **Configurable Storage**: Data directory is independently configurable (e.g. `D:\IdentityData`) and persists across runs regardless of your current working directory.
- **Zero External Database**: Runs entirely local with no database, no server, and no cloud telemetry.

## Installation

### Recommended: Install Globally with `pipx`

For end users wanting a global `identity` command in their terminal:

```powershell
pipx install .
```
*(Or `pipx install identity-cli` once published to PyPI).*

After installation, `identity` is directly available in any directory:

```powershell
C:\Users\User> identity generate
```

### Local Development Installation

Clone the repository and install in editable mode:

```powershell
git clone https://github.com/your-username/identity-cli.git
cd identity-cli
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

## Quick Start

Generate a single identity:

```powershell
identity generate
```

Output:

```text

│          GENERATED IDENTITY             │
╰────────────────────────────────────────╯

Name     : Ethan Brooks
Email    : ethan.brooks482@example.com
Password : V!7qL@92xK#p

✓ Identity generated successfully.
```

Generate with a test phone number:

```powershell
identity generate --phone
```

Output:


## CLI Commands and Options

### 1. `identity generate`

Generate one or more synthetic identities.

| Option | Flag | Description | Default |
|---|---|---|---|
| `--count` | `-c` | Number of unique identities to generate (1 to 10,000) | `1` |
| `--phone` | `-p` | Include reserved test phone number | `False` |
| `--excel` | `-e` | Export batch to Excel `.xlsx` file | `False` |
| `--json` | `-j` | Output in clean JSON format | `False` |
| `--quiet` | `-q` | Suppress decorative status banners | `False` |

#### Batch Generation

```powershell
identity generate --count 10
```

```text
Generating 10 identities...

✓ Generated 10 identities
✓ Uniqueness verified
✓ Identity history updated
```

#### Batch with Phone and Excel Export

```powershell
identity generate --count 10 --phone --excel
```

```text
Generating 10 identities...

✓ Generated 10 identities
✓ Uniqueness verified
✓ Identity history updated
✓ Excel file created

File:
D:\IdentityData\exports\identity_2026-09-05_153000.xlsx
```

#### JSON Output (Single & Batch)

Single identity:

```powershell
identity generate --json
```

```json
{
  "name": "Ethan Brooks",
  "email": "ethan.brooks482@example.com",
  "password": "V!7qL@92xK#p"

```

Batch with phone:

```powershell
identity generate --count 2 --phone --json
```

```json

    "password": "pQ8!xR2#Lm91",
```

### 2. `identity config`

View or update your persistent data storage location.

#### View Current Configuration

```powershell
identity config
```

*(You can also use `identity config --show`)*

```text
Identity CLI Configuration

Data directory:
D:\IdentityData

Exports directory:
D:\IdentityData\exports

Stored names:
127

Stored emails:
127

Stored passwords:
127

Stored phones:
84
```

#### Move Storage to a Custom Path (e.g. `D:\IdentityData`)

```powershell
identity config --data-dir D:\IdentityData
```

```text
✓ Data directory updated successfully.
Persistent data will now be stored in: D:\IdentityData
```

The configuration is saved in your user app data directory (`%APPDATA%\IdentityCLI\config.json` on Windows) and persists across all terminal sessions and current working directories.

## Storage Architecture

All persistent identity records are stored as clean UTF-8 plain-text files with one entry per line:

```text
<data-dir>/
├── data/
│   ├── names.txt       # One full name per line
│   ├── emails.txt      # One email per line
│   ├── passwords.txt   # One password per line
│   └── phones.txt      # One phone per line (if requested)
└── exports/
    └── identity_YYYY-MM-DD_HHMMSS.xlsx
```

### Default Storage Locations

- **Windows**: `%LOCALAPPDATA%\IdentityCLI` (e.g. `C:\Users\<User>\AppData\Local\IdentityCLI`)
- **Linux / macOS**: `~/.local/share/identity_cli`
